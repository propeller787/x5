# 云端数据格式规范

## 1. 概述

本文档定义了VLAGO系统与云端服务器之间的数据通信格式规范。所有埋点数据必须遵循此格式。

---

## 2. 数据格式总览

### 2.1 消息类型

系统支持以下消息类型：

| 消息类型 | type字段值 | 说明 |
|---------|-----------|------|
| 埋点数据 | `trigger` | 系统埋点事件数据 |
| GPS数据 | `chairGps` | GPS定位数据 |
| 车辆信息 | `carInfo` | 车辆状态信息 |
| 健康数据 | `healthInfo` | 健康检测数据 |

### 2.2 数据来源标识

所有消息必须包含 `from` 字段，标识数据来源：

- `"pad"` - 从平板/客户端发送
- `"vlago"` - 从VLAGO系统发送

---

## 3. 埋点数据格式 (type: "trigger")

### 3.1 完整格式

```json
{
  "from": "vlago",
  "type": "trigger",
  "event": "事件名称",
  "timestamp": 1704067200000,
  "timestamp_str": "2024-01-01 12:00:00",
  "node_name": "SceneServices",
  "file": "src/scene/scene_services/src/scene_services.cpp",
  "line": 731,
  "function": "ChangeMode",
  "data": {
    "key1": "value1",
    "key2": "value2"
  },
  "vehicle_id": "VLAGO_001",
  "version": "1.0.0"
}
```

### 3.2 字段详细说明

#### 必填字段

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `from` | string | 数据来源 | `"vlago"` |
| `type` | string | 消息类型 | `"trigger"` |
| `event` | string | 事件名称 | `"mode_switch_start"` |
| `timestamp` | int64 | 时间戳(毫秒) | `1704067200000` |
| `timestamp_str` | string | 时间戳字符串 | `"2024-01-01 12:00:00"` |

#### 可选字段

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `node_name` | string | ROS节点名称 | `"SceneServices"` |
| `file` | string | 源文件路径 | `"src/scene/scene_services/src/scene_services.cpp"` |
| `line` | int | 源代码行号 | `731` |
| `function` | string | 函数名称 | `"ChangeMode"` |
| `data` | object | 业务数据键值对 | `{"old_mode": "standard"}` |
| `vehicle_id` | string | 车辆ID | `"VLAGO_001"` |
| `version` | string | 软件版本 | `"1.0.0"` |

### 3.3 事件命名规范

事件名称使用下划线分隔的小写字母，格式：`类别_动作_状态`

#### 事件类别

- `mode_switch` - 模式切换
- `collision` - 碰撞检测
- `service` - 服务调用
- `sensor` - 传感器数据
- `error` - 错误异常
- `timer` - 定时器

#### 事件示例

| 事件名称 | 说明 |
|---------|------|
| `mode_switch_start` | 模式切换开始 |
| `mode_switch_success` | 模式切换成功 |
| `mode_switch_failed` | 模式切换失败 |
| `collision_check_start` | 碰撞检测开始 |
| `collision_detected` | 检测到碰撞 |
| `service_gears_request` | 档位服务请求 |
| `service_gears_response` | 档位服务响应 |
| `error_lx_camera` | LX相机错误 |
| `error_service_timeout` | 服务超时错误 |

## 5. 数据传输协议

### 5.1 WebSocket协议

- **协议**: WebSocket
- **服务器地址**: `ws://60.205.235.193:3009`
- **消息格式**: JSON字符串
- **编码**: UTF-8

### 5.2 连接流程

1. 客户端连接到WebSocket服务器
2. 建立连接后开始发送数据
3. 连接断开后自动重连（2秒后）
4. 数据通过队列异步发送

### 5.3 消息发送

- 每条消息独立发送
- 消息大小建议不超过64KB
- 支持批量发送（可选）

## 6. 数据验证规则

### 6.1 必填字段验证

云端服务器应验证以下字段：

- `from` 必须为 `"vlago"` 或 `"pad"`
- `type` 必须为已知类型
- `event` (对于trigger类型) 不能为空
- `timestamp` 必须为有效的整数时间戳

### 6.2 数据格式验证

- JSON格式必须正确
- 字符串必须正确转义
- 数字类型必须匹配

### 6.3 数据过滤

云端可以过滤以下数据：

- 无效的时间戳
- 过期的数据（超过一定时间）
- 格式错误的数据

---

## 7. 云端处理建议

### 7.1 数据存储

建议存储到以下数据库：

- **时序数据库**: InfluxDB (适合埋点数据)
- **文档数据库**: MongoDB (适合结构化数据)
- **关系数据库**: PostgreSQL (适合复杂查询)

### 7.2 数据分区

建议按以下维度分区：

- 时间分区（按天/月）
- 车辆ID分区
- 事件类型分区

### 7.3 实时监控

建议监控以下事件：

- 所有 `error_` 开头的事件
- `collision_detected` 事件
- `mode_switch_failed` 事件

### 7.4 数据分析

建议分析以下指标：

- 事件频率统计
- 错误率统计
- 模式切换成功率
- 碰撞检测准确率

const wss = new WebSocket.Server({ port: 3009 });

wss.on('connection', function connection(ws) {
  console.log('Client connected');
  
  ws.on('message', function incoming(message) {
    try {
      const data = JSON.parse(message);
      
      // 验证数据格式
      if (!validateData(data)) {
        console.error('Invalid data format:', data);
        return;
      }
      
      // 根据类型处理
      switch (data.type) {
        case 'trigger':
          handleTriggerData(data);
          break;
        case 'chairGps':
          handleGpsData(data);
          break;
        case 'carInfo':
          handleCarInfo(data);
          break;
        case 'healthInfo':
          handleHealthData(data);
          break;
        default:
          console.warn('Unknown message type:', data.type);
      }
    } catch (e) {
      console.error('Parse message error:', e);
    }
  });
  
  ws.on('close', function() {
    console.log('Client disconnected');
  });
});

function validateData(data) {
  // 验证必填字段

## 10. 附录

### A. JSON转义规则

以下字符需要转义：

- `"` → `\"`
- `\` → `\\`
- `/` → `\/` (可选)
- 换行符 → `\n`
- 制表符 → `\t`

### B. 时间戳格式

- **timestamp**: Unix时间戳（毫秒），整数
- **timestamp_str**: 格式 `"YYYY-MM-DD HH:MM:SS"`，字符串

### C. 数据大小限制

- 单条消息建议不超过64KB
- 队列大小限制为10000条
- 超过限制时自动丢弃最旧数据
