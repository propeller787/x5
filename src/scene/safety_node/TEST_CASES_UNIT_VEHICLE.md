# safety_node 单元测试与实车测试用例

> 依据：`test.md` 全场景目录（S1～S224）、验收模板、必录信号、放行顺序与能力边界  
> 验证层级：`UNIT`（含纯算法 + 节点级注入）/ `VEHICLE`（封闭场地实车）  
> 门禁：P0 全部通过并双人复核后，才允许试产放行

---

## 0. 通用约定

### 0.1 优先级与放行

| 级别 | 含义 | 放行要求 |
|---|---|---|
| P0 | 安全关键 / 签署项 | 全部 PASS 才能进入下一速度阶梯与试产 |
| P1 | 体验与覆盖增强 | 目标工作速度前应关闭 |
| P2 | 感知/优化边界 | 可标记 N/A，不可挡安全放行 |

### 0.2 验收记录（每条必填）

```markdown
### Sxxx / UT-xxx / VEH-xxx 名称
- 优先级：P0/P1/P2
- 验证层级：UNIT / VEHICLE
- 软件版本/Commit：
- 参数版本：
- 车辆编号/载重：
- 地面/坡度/环境：
- 初始速度与挡位：
- 障碍几何和距离：
- 操作步骤：
- 预期状态序列：
- 预期速度/距离/时间边界：
- 实际结果：
- 状态：NOT_RUN / PASS / FAIL / BLOCKED / N/A
- 证据路径：
- 问题单：
- 测试人/复核人/日期：
```

```text

```

另记：控制周期、点云年龄、TF 状态、CPU、丢包、左右最小净空、最小停车余量、是否接触。

### 0.4 实车安全规则

- 软质障碍；操作员持物理急停；安全观察员在场。
- 首轮 ≤ 0.2 m/s；未完成制动标定前禁止 S180 / S186 / S209。
- 无防跌落能力时 S64 / S198～S200 禁止宣称安全（BLOCKED 或 N/A）。
- 动态障碍本代按连续静态观测保守处理（不做速度预测）。
